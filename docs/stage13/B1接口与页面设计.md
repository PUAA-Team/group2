# B1 接口与页面设计

2026-10-29，整体范围已获确认。本批恢复工作台、项目/模型目录、独立数据导入、四步训练及详情标签页。复用现有身份、空间、训练、数据版本和Worker协议，不增加数据库迁移。

## 数据接口

新接口均置于 `/api/v1/workspaces/{workspace_id}` 下，返回统一 data/request_id；列表返回 pagination。

| 接口 | 参数与输出 | 权限 |
| --- | --- | --- |
| `GET /overview` | 项目、排队/运行/完成训练、可用数据统计；最近任务、近期操作 | 必须为可访问空间；各部分按实际读取权限裁剪，受限计数返回null |
| `GET /model-catalog` | q、task_type、category（all/prebuilt/network/trained）、page、page_size；模型及版本、类别、来源训练与结果 | models.read；训练详情链接仍独立校验training.read |
| `GET /dataset-catalog` | q、task_type、page、page_size；数据集及最新版本、样本数、格式、大小与状态 | datasets.read |
| `POST /dataset-previews` | task_type和文件；真实解析校验、摘要、样本数、前50条预览；不创建资产或文件 | datasets.write |
| `GET /project-catalog` | q、page、page_size；项目、训练数量、活跃数、最近任务与最佳分类结果 | training.read |
| `GET /jobs/{job_id}/logs` | 完整已保存日志，以文本附件下载，按事件序号排列 | 对应任务的training.read/services.read及空间权限 |

现有 `/jobs` 增加 status、device_kind、task_type筛选与新旧排序；参数校验拒绝未知枚举。查询仍受空间与任务种类权限约束。已有创建、草稿、提交、停止、评估、服务与版本上传接口保持兼容。

概览聚合与目录查询在服务端完成。分页总数来自相同过滤条件；缺少真实训练或采样时保持空态。模型目录分组依据实际版本来源：已训练产物、内置基础网络和预置权重；无版本资产仍可在“全部”查看并登记版本。

## 页面和操作

训练新建使用 `/train/new`，四步依次为任务与模型、数据集、参数与资源、核对提交。编辑草稿使用相同页面；复制配置生成新的草稿。状态只保存在当前页面内存，切步与布局重绘保留，切换账号或工作空间时清除。保存成功后进入真实任务详情。

数据导入使用 `/datasets/new`，包含任务选择、文件、前50条文本预览/图像包基本信息、格式模板和提交结果。先创建资产再上传时保存已创建ID，上传重试不重复创建资产；版本导入可从既有资产进入。服务端负责最终文件校验。

任务详情使用 `tab=overview|metrics|logs|outputs`，默认概况。概况显示真实执行与配置；指标显示已有曲线；日志按关键词筛选与下载；产物显示校验值、关联模型及评估/部署操作。评估与服务保留各自已有操作。

工作台恢复汇总、最近训练、快捷入口和近期操作。模型/项目目录支持卡片，模型可切换列表与类别，数据列表显示版本、样本及状态。组件沿用已采纳模板，正文不低于14px，不新增解释小字。
