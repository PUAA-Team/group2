# B3 数据与标注设计

本批完成真实样本浏览、图像预览、人工标注协作、版本来源和基础清洗/划分/增强。外部模型候选接入在B4复用这些审核与发布流程。

## 版本和样本

数据版本保持不可变。新增parent_version_id和provenance字段，记录来源版本、操作、种子及数据分区。样本以源版本和从0开始的序号确定身份；图片通过鉴权接口读取已校验ZIP中的文件，不接受任意文件路径。

清洗包含去重、文本首尾空白处理、未标注项过滤与标签映射。固定种子划分生成训练、独立验证、独立测试三个版本；训练任务拒绝选择验证/测试分区。训练器现有内部验证比例仍单独配置，独立分区可用于固定版本评估。图像增强提供水平翻转、亮度和轻噪声；文本提供标点变体。增强与清洗先生成待发布结果，审核预览后才成为新版本。验证/测试分区禁止增强。

## 标注流程

批次固定数据版本、目标样本范围、标签集合和可选分配成员，支持文本分类、整图分类和指令输出编辑。结果具有独立revision，分为草稿、待审核、通过、退回。编辑者保存或提交，批次创建人、空间所有者或管理员复核；通过后批量发布新数据版本，未覆盖样本沿用原版本内容。

标注工作区采用样本队列、中央内容、右侧标签与审核的布局；手机上下排列。每次保存和审核都落数据库，发布与结果写入互斥，发布后不再修改批次。重复发布返回已生成的版本。

## 长任务

新增独立数据操作进程，与API共用已有Python镜像、数据库和受控文件存储，单次处理一个CPU任务；不占用GPU。Compose增加operations服务，本地同样可用独立Python进程运行。请求只登记任务，进程领取后实际执行，前端查询状态与结果。

进程通过运行目录锁避免重复实例。中途退出时保留现场，新进程确认取得独占锁后把未完成执行记为失败，允许用户重新创建；已进入待发布状态的结果保留。取消在处理批次和最终提交前检查。发布通过源/操作行锁、固定摘要和同一事务避免重复版本。

## 接口与迁移

0005_data迁移新增annotation_batches、annotation_results、data_operations，并给dataset_versions增加来源字段。旧账号、资产、执行与文件保持原样。

| 接口方向（均在工作空间下） | 行为 |
| --- | --- |
| 数据版本 `/samples`、`/images/{index}`、`/download` | 分页浏览、标签分布、图片及原文件下载；datasets.read |
| `/annotation-batches` | 批次列表、创建和详情；读取datasets.read，写入datasets.write |
| 批次 `/results/{index}`、`/review`、`/publish` | 结果revision、复核和幂等版本发布，校验成员分配与审核身份 |
| `/data-operations`、详情、`/cancel`、`/preview`、`/publish` | 创建清洗/划分/增强、进度、取消、候选预览、发布；写入datasets.write |

版本存储复用原校验与写入函数，扩展内部完成回调，让新版本与批次/操作的发布记录在一次事务提交。失败只清理本次新文件，原始版本不动。

## 验收

验证文本与图像分页/鉴权、标注分配与修订冲突、审核与发布幂等、真实清洗与增强文件、固定种子划分、验证/测试防泄漏、取消与中断、旧版本和摘要保留。通过浏览器完成导入、标注、发布、处理、训练选择的实际流程；不使用动画代替任务执行。
