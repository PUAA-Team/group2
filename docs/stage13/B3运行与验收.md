## 进程与部署

服务器发布目录为`/srv/model-platform/releases/20261029-13b3`，current已指向此处。数据库迁移到0005_data。Compose在原api、db、gateway之外启动operations服务，共用应用镜像、PostgreSQL和受控文件存储；无新增公网端口和软件依赖。

operations使用运行目录独占锁，单次处理一个数据操作。进程中断的运行任务会在新进程取得锁后记为失败，已进入待发布状态的候选保留。用户取消与最终提交竞争时，以持久状态为准，取消后不会发布新版本。任务失败原因及源版本可从详情查看；重新处理创建新任务。

查看状态可在服务器执行：

```bash
cd /srv/model-platform/current
docker compose --env-file deploy/server/.env -f deploy/server/compose.yaml ps
docker compose --env-file deploy/server/.env -f deploy/server/compose.yaml logs --tail 60 operations
```

本机8002为独立验收库及CPU处理进程，运行文件在D盘qa目录，进程号保存在processes.json。旧本机8000库与失联占用未自动清理，8765原型继续保留。不要把验收库或进程号用于正式运行。
