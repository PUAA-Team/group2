# B4 智能辅助设计

本批把智能标注、智能参数、智能日志接到B2的模型连接与B3的标注、任务和版本流程。真实外部调用需要有效连接、空间授权及逐次输入确认。Agent、工具调用和语义生成式增强继续后置。

## 流程与执行

用户在业务页面选择用途和连接，服务端读取有权访问的对象并生成固定预览；页面展示实际将发送的文字、图像、目标模型和脱敏结果。用户确认摘要后入队，由现有独立operations进程调用供应商。API请求不承担长时间推理，GPU Worker不接收外部API密钥。

operations每轮最多执行一个数据任务和一个智能请求，防止某类队列饿死。HTTP请求有30秒总超时、10秒连接超时及1MiB响应上限；不自动重试可能已经计费的请求。进程中断的调用记为失败并保留记录，重新生成需再次预览确认。取消后仍可能存在已送达供应商的请求，界面如实保留这一边界。

## 空间授权

空间所有者或拥有对应管理权限的管理员设置授权，初始关闭。策略包含允许连接、允许外发类别、每日请求上限、单次样本/文字/输出Token上限。类别为配置统计、日志、文本样本、图像样本；各类分别勾选。

每次调用仍要求assistants.use及源对象读取权限。标注采纳需要datasets.write和批次编辑资格；参数采纳需要training.write；查看者不能创建调用或采纳。用户显式禁用继续优先生效，已有用户组不自动追加新权限。

预览10分钟有效，绑定创建人、工作空间、连接revision、策略revision、对象版本和SHA256。确认及执行前均复核；连接、策略变动或过期时重新生成预览。确认请求在策略行锁下核算当日次数，防止并发突破上限。额度按已确认请求计数，Token只记录供应商实际报告的有效整数，不编造费用。

## 三项业务输出

| 用途 | 服务端构造的输入 | 结果与采纳 |
| --- | --- | --- |
| 智能标注 | 已固定的标注批次、所选样本、标签规范；分类标签或指令输出 | 严格验证样本序号和标签/输出。选中候选写入标注草稿，随后沿用人工提交、复核、发布；保留调用来源与人工修改记录 |
| 智能参数 | 训练器、不可变模型/数据版本、样本统计、设备能力和当前参数；不发送原始样本 | 只接收已支持的参数及逐项理由；校验范围和训练器约束。选定参数形成新训练草稿，保留旧任务和运行配置 |
| 智能日志 | 指定任务、阶段/错误、所选日志序号及脱敏片段 | 输出摘要、原因、证据序号和排查建议；事实引用核对原日志。可选参数调整经校验后形成新草稿，不执行模型生成的命令 |

标注支持文本分类、整图分类与指令输出；图像必须选择vision连接，单次最多4张。图像使用去元数据后的受限PNG，预览展示同一份图片。文本批次单次最多20条。样本和日志中的文字始终作为数据处理。

结构化输出使用确定的JSON字段，允许完整JSON代码围栏；拒绝未知字段、重复/越界序号、范围外参数、无效标签和不存在的日志证据。输入先处理常见凭据、邮箱、手机号等字段，并保留替换数量；脱敏不能保证识别全部业务敏感内容，发送前由使用者检查预览。

指令标注同时补齐输入和指令编辑，结果保存edits及来源，发布时应用到新版本。批次审核和源文件保护沿用B3规则。

## 数据与API增量

0006_assist新增workspace_ai_policies、assistant_requests、assistant_adoptions；给annotation_results增加edits和origin JSON。历史记录通过空对象兼容，旧图、旧资产与模型权重不改。

请求状态为preview、queued、running、succeeded、failed、cancelled、applied；失败包含错误类别和正常字号原因。采纳有唯一请求标识和提交摘要，重复提交返回原结果；不同内容重复采纳明确拒绝。标注记录固定采纳时的样本revision，修改冲突需要重新核对。

接口均在`/api/v1/workspaces/{workspace_id}`下：

| 路径 | 行为 |
| --- | --- |
| GET/POST `/assistant-policy` | 读取和按revision保存空间授权；新策略revision为0 |
| GET `/assistant-options` | 读取允许且有效的连接、用途和限额，凭据不回显 |
| GET/POST `/assistant-requests` | 列表和构造服务端预览；请求体按用途校验源对象 |
| GET `/{request_id}` | 查看预览、结果、错误、用量和采纳目标 |
| POST `/{request_id}/confirm` | 确认预览摘要，原子检查策略、有效期与额度后入队 |
| POST `/{request_id}/cancel` | 阻断尚未开始的调用，或停止采纳执行中调用的结果 |
| POST `/{request_id}/apply` | 标注候选写草稿，或选择参数生成新训练草稿；严格幂等 |

上表后三项路径均位于`/assistant-requests`下。供应商连接、密钥文件及HTTPS地址校验复用B2服务，不在日志、浏览器存储或GPU任务中复制凭据。

## 页面

训练向导参数步骤新增“智能参数”，日志页新增“智能解释”，标注工作区新增“智能标注”。配置在弹窗选择；预览与结果使用独立详情页，保留完整输入检查、逐项建议和采纳动作。用户空间提供授权弹窗，管理页面继续维护连接；不新增重复侧边栏。

页面沿用深青绿主操作、蓝色实体入口、14px正文及紧凑组件。必要的外发说明、错误与建议理由用正常字号；不加入灰色导语或卡片小字。临时草稿只在内存，退出及账号切换清除。

## 验收

覆盖未授权、过期、策略/连接变更、确认摘要篡改、并发额度、跨空间/成员隔离、恶意样本文字、脱敏、错误结构、供应商鉴权/限流/超时、取消与中断、采纳冲突和幂等。三项能力分别走通业务页面；参数和日志采纳不得修改运行任务，智能标注仍经过人工审核后发布。

协议测试使用受控响应；实际供应商验收另外记录连接名称、调用编号、用量和业务结果。没有可用连接时保留明确未验收记录，不用本地规则响应冒充大模型结果。
