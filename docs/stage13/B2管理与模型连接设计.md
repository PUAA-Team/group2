# B2 管理与模型连接设计

本批依据已确认范围补齐全平台管理、系统设置、账号协作和智能连接基础。现有B1云端版本继续运行，新增能力在独立环境完成后再发布。

## 页面

管理员统计独立显示全平台数量、任务状态分布、按日作业和空间统计。数据、模型、作业、审计使用全局查询接口，统一支持空间、名称和状态筛选，列表明确显示空间归属。用户管理补密码重置、有效权限查看与邀请；用户空间补资料/密码、空间更名和成员移除。

系统设置分平台设置、大模型连接、配置记录。新增/修改使用弹窗；供应商连接保存地址、模型名、能力和密钥，列表只显示是否配置凭据。连接测试使用固定测试文本，不发送项目样本或日志。三项业务智能辅助仍按B4的预览确认流程执行。

## 数据与接口

新增0004_admin迁移，只增加platform_settings、model_connections、user_invitations三张表，不修改历史训练和文件。设置按platform或workspace命名空间保存JSON与revision；连接保存公开配置和私有凭据引用；邀请只保存令牌摘要、组/空间、角色、到期和消费记录。

| 接口 | 行为与权限 |
| --- | --- |
| `GET /admin/statistics` | 全局统计，管理员+audit.read；可按空间筛选，按北京时间分日 |
| `GET /platform-info` | 公开平台名称与邀请开关，不返回其他配置 |
| `GET /admin/asset-catalog/{datasets|models|jobs|audit}` | 管理员及对应读取权限；q、space、status、kind、分页 |
| `GET/PATCH /admin/settings` | 管理员+settings.manage；revision并发控制 |
| `GET/POST /admin/model-connections` | 管理员+settings.manage；凭据仅写入 |
| `PATCH /admin/model-connections/{id}` | 修改公开配置/启停/更换密钥，If-Match |
| `POST /admin/model-connections/{id}/test` | 固定测试请求、超时、结构校验、状态记录 |
| `POST /admin/invitations` | 管理员+users.manage；返回一次性邀请链接所需令牌 |
| `POST /auth/register` | 必须有有效单次邀请；不能自选管理员、组或权限 |
| `PATCH /auth/profile`、`POST /auth/password` | 本人资料和原密码验证；改密撤销全部会话 |
| `POST /admin/users/{id}/password`、`GET /admin/users/{id}/access` | 管理员+users.manage；重置撤销会话，有效权限只读 |
| `PATCH /workspaces/{id}`、`POST /workspaces/{id}/members/{user}/remove` | members.manage且空间所有者/管理员；保护所有者 |

公共注册保持关闭。内部邀请由管理员确定组、空间和角色，到期或已用令牌不可注册；创建用户与消费邀请在同一事务完成。

上传与样本上限在真实预览和版本导入时生效；全局并发通过数据库策略行锁串行核验，包含持续服务和失联保留占用。上传硬上限仍为10MiB，配置允许管理员在此范围内收紧。

密钥保存在运行目录private/connections下的0600文件，目录0700，数据库只保存文件引用。接口、审计、错误和截图不返回密钥。连接只支持管理员配置的HTTPS端点，不跟随重定向；调用前拒绝回环、私网、链路本地和元数据地址。无新增依赖，使用已有HTTPX。

## 验证

覆盖全局查询的管理员边界与筛选分页、设置revision冲突、密钥不回显、连接错误/超时、邀请并发单次消费/过期/权限注入、密码重置与旧会话失效、所有者保护及旧库升级。连接协议使用测试替身；没有真实供应商配置时不宣称真实连接已验收。
