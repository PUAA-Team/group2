# 公开数据实验设计

## 数据与实验

采用UCI SMS Spam Collection（短信二分类，CC BY4.0）和Zalando Fashion-MNIST（服装图像十分类，MIT）。来源、许可、原始压缩文件摘要及实际计数随准备脚本记录。使用公开文件下载，不增加依赖，不发送数据到外部大模型。

SMS先按规范化文本去重，冲突标签单独记录并剔除，再按标签分层划分80%开发池和20%独立测试集，随机种子42。平台训练器从开发池再划分20%验证。固定测试文件不参与训练或参数选择。文本分类预定对照为5epoch与25epoch，学习率0.01/0.03，报告准确率、Macro F1、混淆矩阵及多数类基线。

Fashion-MNIST保持官方训练/测试来源分离，分层抽取6000张开发图与2000张测试图，各类均衡。过滤重复像素及跨集合重复，保存原始28×28灰度PNG；平台的固定预处理转RGB并缩放32×32。TinyCNN预定3epoch与10epoch，学习率0.003，batch32；测试集独立，报告准确率、Macro F1与混淆矩阵。多数类基线为10%。

Qwen3-0.6B LoRA使用SMS开发池的512条平衡指令和测试集的128条平衡短信。1epoch、微批1、梯度累积4、长度192、rank4、学习率0.0002。先记录响应Token loss，再由实际服务对128条测试短信逐条生成ham/spam，统计标签准确率、Macro F1、混淆矩阵及无效输出。该组只说明微调后表现；同测试条件下的原始Qwen基线作为后续补充，当前结果不用于量化微调增益。

训练、评估和服务均在现有8000平台创建，归入公开数据实验项目，模型与数据版本固定。全部使用现有GPU Worker和额度，单GPU顺序执行，已有CPU演示服务保留。用户已有任务优先按提交顺序正常排队，不强制取消。训练失败记录原因，不替换成演示结果。

## 验收和复现

每组保存来源、摘要、样本ID、标签分布、划分、配置、平台任务ID、真实曲线和独立测试指标。对照方案提前固定，结果无论高低都保留。所有原始文件、ZIP/CSV/JSONL、日志和模型仍放D盘。先做数据互斥与格式检查，再导入平台并运行。

资料：[UCI SMS](https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection)、[Fashion-MNIST官方仓库](https://github.com/zalandoresearch/fashion-mnist)、[官方中文说明](https://github.com/zalandoresearch/fashion-mnist/blob/master/README.zh-CN.md)。
