# 真实前端实现与验收设计

## 本批目标

登录后使用真实数据库管理工作空间、成员、账号、用户组、模型和数据集。文件上传生成真实不可变版本，预览来自存储文件。浏览器刷新和重新登录后保留数据。失败直接反馈，不切换为原型数据。

## 页面与交互

沿用已确定的云管控导航、全部默认展开、滚动位置保留、折叠只剩图标。共享原型的 UI 组件和样式，不重做配色：正文 #252525，背景 #f4f5f7，主操作 #276d62，详情入口 #1664c0，边框 #e3e5e8；微软雅黑与系统中文无衬线字体，正文及控件不低于 14px，标题 22px，面板/控件/弹窗圆角 8/6/10px。

工作台显示当前空间的真实资产数量和操作入口。空间页管理空间及成员。模型和数据列表支持搜索、分页、刷新及详情；模型详情登记来源版本，数据详情导入文件、查看实际统计和样本。管理页提供用户、用户组和组/个人授权配置，操作记录来自空间审计。

新增、修改、授权、成员、版本导入采用弹窗。错误在当前表单正常字号展示；保存中禁止重复提交，失败保留输入。显示名称使用加粗蓝色详情入口；状态列表只显示可聚焦圆形语义图标，悬停可读文字。短类型和版本用标签，取消解释小字。复杂字段和长样本允许局部滚动，页面不横向溢出。

所有原菜单保留。尚无真实后端的页面显示待接入状态，提供已实现页面入口，不用旧模拟记录填充。账号及组管理受平台管理员和动作权限控制；资产操作按当前空间角色及权限显示，服务端再次校验。

## 接入结构

新增 `frontend/live`，按请求客户端、状态/路由、页面、弹窗和事件拆模块。通过后端静态资源挂载提供同源页面，主入口 `/`；API 继续 `/api/v1`。仅挂载前端资源，不暴露后端、数据库、运行日志或 docs。原型文件不覆盖。

Cookie 为 HttpOnly，CSRF 仅留内存。localStorage 仅存导航、折叠、选中空间等界面偏好。过期会话回到登录；不使用原型用户和密码。每次导航刷新身份和当前空间授权，迟到响应不得覆盖已切换的页面。

## 必要接口补充

1. 本机初始化状态及管理员创建：`GET/POST /api/v1/setup`。默认关闭浏览器初始化；只在显式开启、回环客户端和本机 Host 下可创建。一次性检查与写入使用数据库锁，初始化后拒绝再次执行，不修改表结构。初始化不允许提交组、授权或任意角色字段。默认以管理员创建，密码由使用者设置。
2. 登录和当前会话返回本人有效权限与配额，支持没有空间时的前端权限呈现。
3. `GET /api/v1/workspaces/{id}/members` 仅空间管理者可查。成员新增支持使用已有用户账号，界面无需填写内部 ID；保留原 user_id 请求兼容。
4. 用户、用户组、模型和数据列表补名称/账号搜索参数 `q`，保持原分页与权限规则。

本机允许来源补充 8000 的精确回环地址。生产浏览器初始化保持关闭，继续使用部署 CLI；HTTPS、PostgreSQL 和远程访问仍单独验收。

## 验收

后端检查初始化开关、回环和来源限制、二次初始化冲突、权限摘要、成员读写及搜索隔离。客户端测试 HTTP 错误、CSRF、上传、会话失效和版本并发；渲染测试检查转义、权限按钮、非模拟数据与弹窗。

浏览器在独立 D 盘测试数据库及既有隔离 Chrome 配置中完成：初始化/登录、创建组和用户、空间和成员、模型及版本、CSV/JSONL 上传、样本预览、刷新后读取、权限拒绝与退出。检查 1440/1024/390 宽度、弹窗、侧栏滚动和状态悬停，保存实拍及记录。应用库只通过使用者在页面的明确操作写入；验收数据不混入应用库。

已补充两项复现回归：打开新弹窗时清除上一操作提示，避免遮挡手机底部按钮；无法读取组目录时保留用户当前 group_id，避免仅修改姓名却清空分组。

参考 [FastAPI 静态文件挂载](https://fastapi.tiangolo.com/tutorial/static-files/)及[官方代码仓库](https://github.com/fastapi/fastapi)，使用显式资源目录。弹窗按 [WAI-ARIA 模态对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)核对聚焦、Tab 循环、Escape、背景不可交互与关闭后的焦点返回。视觉继续遵循已采纳的[云管控规范](../stage4/云管控型前端模板提示词.md)。
