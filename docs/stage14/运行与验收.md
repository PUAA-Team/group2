## 导入带不同字段名的数据

进入“数据集 → 导入数据集”，选择任务类型及文件。标准CSV、JSONL、图像ZIP仍可按原流程上传。字段名不同时，点击“字段映射”，为每个目标字段选择原字段，再点击“校验并预览”。

文本分类选择文本字段，标签可选择“不提供”并进入后续标注。指令数据选择指令、输入和输出，输入可省略；图像ZIP对labels.csv的图片路径、标签列进行映射，图片保持原字节。未选字段以标签列出，重复指派和缺少必需字段会明确报错。更换文件、任务类型或映射会清除旧预览。

保存后，平台使用标准文件执行训练。版本来源中保留原文件名、摘要、字节数、映射及忽略字段；版本本身的摘要和额度对应实际保存的标准文件。原上传文件不额外保留一份副本。下载得到标准化版本，原始文件由上传者自行保留。

## 复用训练参数

训练向导第三步“参数与资源”提供模板选择、应用、另存与管理。

- 配置参数后点击“另存模板”，在弹窗填写名称并保存。
- 选择模板后点击“应用”，只更新训练参数，已选模型、数据版本、节点和任务名称保留。
- “管理模板”可以弹窗修改、归档与恢复。模板在工作空间内共享，读取需要training.read，维护和应用需要training.write。

模板绑定任务类型和训练器，同一训练器下可用于不同模型版本。文本/图像模板保存五个通用参数；Qwen另包含最大长度和LoRA rank。模型、数据、设备、优先级、凭据及在线服务指令不写入模板。智能参数采纳后的配置也可以从向导另存。

修改模板不会自动修改当前草稿，也不会改变已保存任务。若模板在选择后被其他成员更新，应用会提示重新选择；归档模板不能用于新应用。启用状态使用既定的成功符号，列表仍只显示符号，悬停或键盘聚焦可见状态文字。

三种常规视口为1440、1024、390。受检字号至少14px，无整页横向溢出或JavaScript异常；两类布局结果独立保存。管理员尚无数据处理或智能请求时按真实空态验收。

实际页面导入32条合成文本，选择“正文/分类”映射并忽略编号；创建模板、修改、归档恢复后应用3个epoch，从页面提交CPU训练。训练完成后核对权重下载摘要，再对同一数据版本执行评估并加载为CPU服务，真实推理输出属于训练标签集合。该合成集用于流程检查，其高准确率不外推为模型泛化结论。

另创建隔离成员，验证加入空间前无法访问，加入后按组授权读取。所有者将8条未标注样本分配给成员；成员提交后不能自行审核，所有者审核发布新版本。真实去重8→4条，成员用清洗版本及共享模板完成CPU训练。成员降为查看者后写入立即拒绝，历史结果仍可读取。旧数据版本保持原标签和摘要。

两个CPU容器还完成既有训练、同数据对比、错误样本、服务调用和密钥轮换流程；它们共用一台ECS。三项智能辅助的真实供应商证据沿用B4合成调用，本轮没有发起新的供应商调用或打开生产外发策略。

## 故障与恢复

隔离CPU任务使用256条合成样本、100个epoch和batch1检查断网恢复。子进程已经启动后断开该Worker的测试网络；训练在本机容器内完成，控制端在未收到结束回执时继续保留设备。重连后原执行上传产物、补齐回执，下载摘要一致。随后在空闲状态重启Worker和验收API，节点身份、原执行及暂停状态保留，没有重复注册节点。训练中强制杀进程及长时间断网尚未在本轮实测。

服务器内另创建新的目录与无公网入口的PG容器，从pre-stage14备份恢复。16个存储对象字节数、10个数据版本摘要及模型产物校验一致；原CUDA任务仍已完成，原准确率0.5保留。恢复库从schema9升级10，使用原账号完成登录、空间和统计查询。测试库及恢复文件都留服务器，没有覆盖生产运行目录或下载备份。

复核中先通过失败测试定位并修正两项问题：弹窗和向导复用了参数输入框ID，现已分开；ZIP重新打包使用当前时间戳，现已复制原ZipInfo，跨时间预览和上传得到相同摘要。最终视觉检查另修正启用模板的语义符号。验收脚本的模型版本夹具、完整默认参数比较、登录会话及结果文件隔离问题均已修正并重跑，没有将失败轮次计作通过。

current指向`/srv/model-platform/releases/20261031-14a1`。功能发布前停api/operations后备份，服务器位置`/srv/model-platform/backups/pre-stage14-20261031`包含数据库、storage与受限配置。0010只新增参数模板表，未修改既有业务表。发布脚本`scripts/deploy_stage14.py`先验证最终镜像、PostgreSQL、浏览器、成员和真实训练记录，再迁移并切换。

局部UI修订由`scripts/deploy_stage14_ui.py`发布，只更新前端和缓存标识；通过后端/Worker逐文件SHA256比较复用157项已验证来源，重新执行120项前端及两种宽度状态检查。没有以旧镜像测试结果替代不同后端代码。

退回功能版本14a时，保留schema10和新增数据，切换应用目录即可：

```bash
cd /srv/model-platform/current/deploy/server
docker compose --env-file .env stop operations api
ln -s /srv/model-platform/releases/20261031-14a /srv/model-platform/current-rollback-stage14
mv -Tf /srv/model-platform/current-rollback-stage14 /srv/model-platform/current
cd /srv/model-platform/current/deploy/server
docker compose --env-file .env up -d --no-deps api operations
docker compose --env-file .env exec -T gateway nginx -s reload
```

执行前确认没有在途任务，临时链接名称应未被占用。若需退到B5b，使用已验证识别schema10的`20261031-13b5b-compat10`，新增模板记录仍保留；不将旧库恢复覆盖现有库。
