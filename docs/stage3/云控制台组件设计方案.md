# 云控制台组件设计方案

本轮提供云管控型与团队协作型两套视觉体系，各自包含训练任务、任务详情、资源管理和组件规范。云管控型为当前主方向，默认海军蓝、纯文字状态与微圆角；两套使用相同业务数据，可即时调整配色、状态显示和边角。现有原型与上一轮四套样例均保留，采纳后再统一迁移。

## 参考与取舍

阿里云设计中心将 Xconsole 列为云产品管控设计体系。本方案参考其控制台定位，以及 PAI 的任务管理、配置分组和详情页签组织。PAI 把任务概览、事件、监控、日志分开，适合训练生命周期管理；本平台将训练指标、日志、配置和产物作为四个详情页签。

腾讯云 TI-ONE 的真实配置截图采用清晰的字段标签、分组操作和右侧资源看板。团队协作型保留这些交互思路，结合 TDesign 的组件体系组织页面；资源详情使用右侧抽屉，普通新建使用居中弹窗。

本项目的字号、尺寸和配色见下表，均为样例方案值。当前公开的阿里云旧组件文档作为历史组件参考；两套样例属于本项目的设计适配，页面没有使用厂商标识。

## 基础规则

| 项目 | 云管控型 | 团队协作型 |
| --- | --- | --- |
| 主要用途 | 高频查看、批量管理、运维操作 | 日常训练、配置与团队协作 |
| 正文／任务名称 | 14px／14px | 14px／14px |
| 主标题／区块标题 | 22px／16px | 24px／16px |
| 表头／辅助数据 | 12px／12px | 13px／12px |
| 按钮与输入字号 | 14px | 14px |
| 标准控件高度 | 32px | 36px |
| 基础任务行高 | 58px | 64px |
| 默认控件／面板／弹窗圆角 | 2px／4px／6px | 2px／4px／6px |
| 侧栏宽度 | 208px | 224px |
| 页内边距 | 24px | 28px |
| 新建弹窗宽度 | 580px | 680px |
| 详情抽屉宽度 | 460px | 520px |

中文优先使用系统的微软雅黑或苹方。数据使用等宽数字；日志和命令使用 Consolas。界面不依赖在线字体，在本机打开即可展示。必要的 ID、时间和设备信息使用 12px，业务标题和任务名称使用正文层级；页面不追加功能介绍小字。

### 色彩

云管控型采用灰色导航、深色全局栏和白色内容面板：画布 `#F4F5F7`，正文 `#252525`，辅助文字 `#737780`，分隔线 `#E3E5E8`，默认主色 `#2B5278`。主要操作、链接、选中页签、运行状态与训练曲线同步使用当前配色。

团队协作型采用白色导航与全局栏、浅灰画布：画布 `#F3F5F8`，正文 `#182334`，辅助文字 `#6B7685`，分隔线 `#E4E8EE`，默认主色 `#3268A8`。本轮收紧正文、控件和行高，并移除列表顶部重复的四项统计。

顶部“外观”提供海军蓝、石墨灰、深青绿、湖蓝、砖红与橙色，并支持自选颜色。按钮文字按背景选择深浅，浅色主色保留深色边框；对白底的文字链接保持至少 4.5:1 对比度。两套方案分别保存设置，切换和刷新后仍保留。

状态颜色承担业务含义：主色运行、绿色完成、琥珀色等待、红色失败。状态同时显示文字；列表不依靠颜色区分任务。组件不使用渐变、玻璃效果、装饰性阴影或自动播放动画。

### 主面板和状态样式

详情、资源与组件页由一个连续主面板承载内容。内部区域用标题、留白或分隔线区分，区块不再分别带外框。微圆角模式仅给外层面板 4px、控件 2px、弹窗 6px；内部图表、节点和分区保持平直。另提供直角与柔和圆角，方便实际比较。

状态默认显示简短文字。线框标记采用细边框与紧凑内边距，图形符号采用运行、等待、完成和失败各自的符号；三个选项均去掉彩色小圆点与浅色胶囊底。状态颜色中的运行色跟随主色，完成、等待和失败保留业务语义颜色。

## 组件规范

下列规则对选定体系内的所有页面生效。已有样例展示常用组件；登录、标注及其余业务页面按映射迁移。

| 组件 | 统一规则 | 两套体系的区别 |
| --- | --- | --- |
| 全局栏、面包屑 | 工作空间与用户操作放全局栏，页内仅保留当前位置 | 深色紧凑栏／白色宽松栏 |
| 二级导航 | 五组默认展开；记忆手动状态；切换保留滚动位置；收窄保留分组状态 | 34px 灰底平直项／40px 白底分区项 |
| 当前菜单 | 整项浅色背景与文字强调 | 两套均去除左侧竖条 |
| 主、次、危险按钮 | 一块操作区只强调主要提交；危险操作二次确认；禁用显示不可用状态 | 32px／36px 控件，共用边角设置 |
| 图标与文字链接 | 图标 16～18px；图标按钮有名称和焦点；链接用于详情或轻操作 | 12px 表格操作／14px 表格操作 |
| 文本、数字、密码输入 | 默认、悬停、焦点、错误、禁用采用同一组边框；密码入口沿用同尺寸 | 无外圈的细边框／带轻焦点外圈的边框 |
| 单选下拉 | 控件与展开选项同宽；列表当前项带勾选；支持方向键、Enter、Escape、Tab | 32px 选项／38px 选项 |
| 搜索与筛选 | 状态和关键词可组合；空结果给出重置入口；排序在表头 | 紧凑操作栏／宽松操作栏 |
| 复选、单选、开关 | 状态可键盘操作；选中同时有形状标记；不可用选项禁用 | 14px 小方框／16px 轻圆角框 |
| 标签、多选和权限树 | 标签沿用状态尺寸；移除有明确按钮；权限层级使用缩进与复选框 | 平直标签与紧凑缩进／轻圆角标签与较大间距 |
| 表单标签与分组 | 必填符号一致；错误紧邻字段；高级参数独立分组 | 横向标签、逐行字段／纵向标签、两列字段 |
| 多行文本与代码 | 多行内容独立滚动；日志保留可辨认时间、级别和内容 | 浅底日志区／深底日志区 |
| 上传与日期选择 | 外框、菜单、焦点沿用输入规范；上传显示文件与校验状态；日期按统一格式 | 对应 32px／40px 输入体系 |
| 表格 | 选择、名称、状态、信息和操作有固定顺序；长表在内部横向滚动 | 模型独立列、细进度／模型随任务名称、状态与进度合并 |
| 分页 | 总数、每页数量和当前页位置统一；不可翻页按钮禁用 | 28px 页码／32px 页码 |
| 页签 | 同一业务切换采用页签；选中由文字和底线共同表达 | 均为 14px、2px 主色底线 |
| 步骤条 | 仅用于真实的多步流程；完成、当前、未开始有不同标记 | 方形编号／圆形编号 |
| 状态、进度条 | 状态名称统一；停止为已停止，排队取消为已取消 | 三种可选状态样式；3px／6px 进度 |
| 图表、统计、指标 | 指标带名称和单位；不同任务展示对应指标；颜色与线型保持一致 | 24～26px 数字；图表共用主面板 |
| 数据与模型预览 | 预览图保留业务内容；名称、类型和版本按统一文字层级 | 紧凑资产列表／较宽松的资产区块 |
| 普通弹窗 | 新增、编辑、权限配置、停止确认使用弹窗；提交区固定；Escape 可关闭 | 18px 标题、浅底底栏／20px 标题、白底底栏 |
| 详情抽屉 | 用于节点、资源占用、错误详情等旁路查看；不替代主要工作页面 | 460px／520px |
| 气泡提示、通知与警告 | 操作反馈简短；错误提供对象与原因；鼠标与键盘均可触发必要提示 | 颜色与边框按体系复用 |
| 空状态、加载、错误页 | 提供下一步操作；加载占位保留原结构；错误不显示成功数据 | 字体、间距与图标按体系复用 |

复杂训练向导和带预览的数据导入保留独立页面。普通用户新增、资源配额、任务修改等采用弹窗。移动端导航改为抽屉，表单改为单列或参数双列，表格在自身区域横向滚动，主页面保持在视口内。

## 现有页面映射

工作台、用户空间和统计面板采用同体系的指标、列表和表单；资源监控采用图表与节点详情抽屉。数据集、模型仓库和在线服务统一列表、筛选、版本标签与操作列。训练项目和评估页使用同组页签、曲线与比较表，训练任务使用本轮的列表和详情。

在线标注保留画布，外围工具栏、标签选择、标注列表和保存操作遵循组件规范。数据增强采用处理列表与参数弹窗。API KEY 管理、用户、用户组、权限、系统设置采用同组输入与确认弹窗。管理端数据、模型、作业和操作记录复用表格体系，避免各页自行定义按钮和行高。

登录与注册按同体系文字层级、输入、错误和主要操作设计，保留独立页面。新建登录页不复制业务统计卡片、宣传介绍或图表。

## 样例范围与采用方式

本轮实际实现八个审查页面，以及外观调节、新建、复制、停止、节点登记和详情抽屉。组件规范页集中展示字体、按钮、菜单、输入、下拉、状态、复选、单选、开关、提示、表格、分页、页签、步骤、进度、空状态与加载。上传、日期、权限树、标注工具和登录页面仍使用现有原型，采纳方案后按上述规则迁移。

建议先选择正文与信息密度，再确认表单和弹窗。若采用组合方案，应确定唯一的基础字号、控件高度、状态规则与间距，随后统一应用到整个平台。当前两套保持独立，原型没有被替换。全部训练指标、节点状态与演示操作均来自前端样例数据。
