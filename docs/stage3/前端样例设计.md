# 前端视觉方案审查

本次提供四套独立样例，每套包含工作台、训练详情和资源管理。各方案使用同一组模拟任务、数据和设备，便于比较布局、阅读顺序与操作位置。样例代码位于 `frontend/design-review`，当前原型保持原样。

## 四套方向

| 方案 | 布局重点 | 基础颜色 | 适用页面 |
| --- | --- | --- | --- |
| A 精密工作台 | 弱化侧栏，任务列表直接占据主体，指标合并为摘要 | 白 `#ffffff`、灰 `#f7f8fa`、石墨 `#202735`、蓝灰 `#334d69`、边界 `#e3e6eb` | 日常工作台、任务管理 |
| B 实验室 | 曲线与实验对照优先，配置和执行信息分置侧区 | 白 `#ffffff`、灰绿 `#f1f4f3`、深绿灰 `#202c2a`、墨绿 `#245a50`、边界 `#dce5e1` | 训练详情、模型评估 |
| C 资源控制台 | 深蓝导航与浅色正文，设备和队列采用紧凑布局 | 白 `#ffffff`、灰 `#edf0f4`、深蓝 `#23374b`、蓝 `#295b87`、边界 `#dae0e7` | 资源监控、管理页面 |
| D 轻量工作室 | 资产预览与项目内容并列，列表和卡片按用途组合 | 白 `#ffffff`、浅灰 `#f5f7fa`、石墨 `#2c3540`、蓝灰 `#3c647a`、边界 `#e0e6eb` | 数据集、模型仓库、个人工作台 |

共同采用系统中文字体，普通正文 14px，标题 22～26px；命令、运行标识和日志使用等宽字体。主要内容左对齐。表格保持稳定的列宽和数字对齐，图表颜色代表训练系列或设备状态。

### A 精密工作台

保留两级导航，侧栏采用浅灰色。工作台首先显示运行中的任务和待处理项，摘要使用横向分隔。训练详情以状态、关键指标、曲线和参数构成一个连续的工作区域，减少多层容器。资源页默认采用设备列表。

### B 实验室

训练曲线作为工作台的主要内容，右侧查看当前实验，下面比较同项目的训练配置。训练详情提供指标、日志和参数页签。资源页围绕运行中的训练展示设备分配和显存使用。视觉重点是实验结果及其配置关系。

### C 资源控制台

导航采用深蓝色，内容区保留白底。首页突出节点可用性、运行队列和设备矩阵，表格使用紧凑行高。训练详情将执行阶段和日志集中排列；资源页提供设备、节点和队列视角。

### D 轻量工作室

工作台上部展示当前项目及可继续的训练，数据和模型用样本预览与明确标签识别。训练详情保留较宽的图表和留白，资源以节点卡片呈现。卡片用于可独立识别的项目或设备，参数和操作记录使用列表。

## 交互边界

菜单默认全部展开，手动展开和侧栏收窄状态使用独立存储键保存。切换方案或页面保留菜单滚动位置。二级菜单使用底色提示当前位置，不使用蓝色竖条。新增训练与节点配置通过弹窗进行；弹窗包含焦点管理、关闭按钮和 Escape 关闭操作。

样例支持任务筛选、任务详情、曲线视图、日志页签、设备详情、模拟节点登记和方案选择。仅审查页签提供三类示范页面，其余菜单保持完整并清楚显示样例范围。训练、探测、提交与指标均为模拟能力，不连接后端，不执行代理安装，不修改现有原型数据。

## 审查方式

先对比四套工作台，再检查训练详情和资源管理。选择时可分别记录导航、列表密度、按钮、表单与图表的偏好。推荐将一种风格作为基础，再组合实验详情或资源页面中的业务布局，保持整个系统的控件规则一致。
