# 云控制台样例运行说明

本轮提供两套组件体系，每套含训练任务、任务详情、资源管理和组件规范。点击顶部方案名称可保留当前页面切换外观，选择仅保存到本机浏览器。现有原型及上一轮样例保留。

## 操作与限制

任务可按状态、关键词筛选和按时间排序。新建任务在弹窗内选择类型、模型、数据和参数；图像分类、目标检测、文本分类分别匹配预置模型与数据。列表支持复选并停止选定的运行任务，排队任务可以取消。普通操作和危险确认均使用弹窗。

资源页提供节点与队列视图。登记节点后状态为待审核，不计入在线节点；命令为不可执行的示意。资源详情抽屉展示配置、分配和事件样例。菜单默认全部展开，手动展开、收窄状态和方案选择使用独立存储键 `model-training-cloud-review-v2`，不影响现有原型。

模拟任务与节点只存在于当前页面会话，刷新恢复初始数据。样例未接入身份服务、训练执行、模型文件、硬件探测、调度、资源配额校验或权限服务。资源与指标显示为固定演示数据。其余菜单提供审查范围提示；该轮没有迁移现有全部业务页面。

## 重新启动与检查

在仓库根目录运行下列命令，无需安装依赖：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8766 --bind 127.0.0.1 --directory frontend/design-review
```

启动后访问选择入口；如果 8766 已运行样例，直接打开即可。前台服务可按 `Ctrl+C` 停止。浏览器空白或连接失败时先确认服务仍在运行；`.js` 模块须返回 `application/javascript`，本机不用 `.mjs` 作为浏览器模块入口。

运行前端测试：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --test --test-isolation=none frontend/design-review/cloud-v2/review.test.mjs
```

本轮完成 25 项样例测试，全部前端共 52 项通过；浏览器检查覆盖 8 个页面在 1280、768、390px 下的 24 项布局和 24 项交互。布局没有页面级横向溢出，表格允许内部横向滚动。交互检查覆盖外观切换与保存、浅色可读性、菜单浮层、紧凑尺寸、手机外观抽屉、调色预览亮度，以及任务联动、新建、停止与取消、日志、节点待审核、抽屉和筛选搜索。上一轮另检查了菜单记忆、滚动、Escape 与手机导航。

浏览器实测：云管控型正文 14px、主标题 22px、控件 32px、任务行约 58px；团队协作型正文 14px、主标题 24px、控件 36px、基础任务行高 64px（本机缩放下实测约 64.57px）。[检查记录](../../frontend/design-review/cloud-v2/previews/browser-audit.json)保留实际尺寸与结果。

入口、样式与界面模块使用统一的 `palette-3` 版本标识，避免缓存导致部分更新。调色抽屉保持页面原亮度，普通资源详情继续使用遮罩。若旧页仍没有“外观”按钮，使用上方带 `review=palette` 的入口重新打开，无需清除浏览器数据。
