# 资源接入 SPEC

接入码绑定空间、用途、创建人和期限。已过期、被撤销或创建人失去授权后不能注册。普通成员只能申请自己空间的节点，准入仍由管理员控制。注册、摘要存储、稳定设备、心跳时间和探测结果必须真实。

Worker 普通网络与自检仅依赖标准库，训练 Python 可独立指定。所有路径在受控 Worker 根目录；不从服务端接收任意 shell、Python 表达式或安装脚本。打包排除测试、缓存、凭据和本机配置，摘要可重复校验。

页面从生成申请、复制遮蔽命令、等待连接到审核与设备列表保持统一交互。离线或探测失败显示真实未知信息，不显示 0 利用率或模拟 GPU。数据读取、长短期身份、日志和资源凭据用途分别验证。

测试覆盖：无权限、跨空间、CSRF、接入码到期与复用、同请求重试、不同摘要拒绝、伪造凭据、无效协议、设备重复、真实心跳、探测请求确认、暂停/撤销、失联不释放，以及打包不含秘密。浏览器验证普通资源页与管理员页、命令复制、状态和响应式。最后使用本机真实 RTX 4060 接入，保存 UUID/显存/驱动与 CUDA 运算证据。
