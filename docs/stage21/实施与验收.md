# Stage 21A 实施与验收：空间自治与团队治理

## 完成范围

1. **数据库迁移与模型扩展（`0017_workspace_governance`）**
   - [0017_workspace_governance.py](../../backend/migrations/versions/0017_workspace_governance.py)：`memberships` 新增可空 `quota` JSON 列，新增 `workspace_budgets` 表（空间总预算）。
2. **4 级空间角色与所有权转让**
   - [permissions.py](../../backend/src/model_platform/permissions.py)、[schemas.py](../../backend/src/model_platform/schemas.py)、[workspaces.py](../../backend/src/model_platform/api/workspaces.py)：支持 `admin`（空间管理员）、`editor`（研发成员）、`annotator`（标注员，仅限数据标注与预览）与 `viewer`（查看者）；新增 `POST /api/v1/workspaces/{workspace_id}/transfer-owner` 支持带 `If-Match` 乐观锁的所有权转让。
3. **本空间设备自治权下放**
   - [governance.py](../../backend/src/model_platform/api/governance.py)：新增 `GET/POST /api/v1/workspaces/{workspace_id}/devices/{device_id}/policy` 与 `GET /api/v1/workspaces/{workspace_id}/resource-principals`，允许空间管理员配置已归属本空间设备的用途与本空间成员白名单（禁止越权选择非本空间成员或修改全局用户组规则）。
4. **空间总预算、成员子配额与空间账单**
   - [budgets.py](../../backend/src/model_platform/services/budgets.py)、[jobs.py](../../backend/src/model_platform/services/jobs.py)、[scheduler.py](../../backend/src/model_platform/services/scheduler.py)：新增 `GET/POST /api/v1/admin/workspaces/{workspace_id}/budget` 与 `GET /api/v1/workspaces/{workspace_id}/governance/summary`，调度与存储扣额按平台配额、空间总预算、成员子配额三层收敛。
5. **前端空间治理界面**
   - [overview.js](../../frontend/live/pages/overview.js)、[dialogs.js](../../frontend/live/dialogs.js)、[compute.js](../../frontend/live/compute.js)、[governance.js](../../frontend/live/governance.js)、[events.js](../../frontend/live/events.js)、[app.js](../../frontend/live/app.js)：在 `/space` 展示 4 级角色、空间子配额、所有权转让及“空间预算与成员账单”看板；在 `/monitor` 对本空间管理员开放设备“配置策略”弹窗。
