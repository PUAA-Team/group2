# 数据模型与状态约定

## M1 持久对象

所有标识由服务端生成，使用带类型前缀的随机 UUID。时间统一存 UTC，API 输出带时区的 ISO 8601；界面可以转换北京时间。名称不作为外键或资源身份。

| 对象 | 主要字段 | 约束 |
| --- | --- | --- |
| UserGroup | id、name、allow_actions、deny_actions、quota、revision | 名称唯一；未知权限和负数上限拒绝 |
| User | id、account、display_name、password_hash、is_admin、active、group_id、allow_actions、deny_actions、quota、revision | account 规范化后唯一；敏感字段不进入输出 |
| Session | id、user_id、token_digest、expires_at、created_at | 高熵令牌摘要唯一；过期/账号禁用时拒绝访问 |
| LoginAttempt | key_digest、failures、blocked_until | 登录失败限制持久化，错误消息不区分未知账号与密码错误 |
| Workspace | id、name、owner_id、revision | 资产归属以此隔离；成员不随便读取其他空间 |
| Membership | workspace_id、user_id、role | 组合唯一；角色 editor/viewer 限制空间写入 |
| ModelAsset | id、workspace_id、name、task_type、trainer_id、source_ref、revision | 模板与任务匹配；登记不等于可训练 |
| ModelVersion | id、model_id、version、source_ref、status、created_by | 同模型版本号唯一，已发布版本内容保持不变 |
| Dataset | id、workspace_id、name、task_type、revision | 数据集与数据版本分开，不能原地覆盖历史版本 |
| DatasetVersion | id、dataset_id、number、format、filename、storage_key、sha256、size_bytes、sample_count、status | 版本号在数据集内唯一，文件指向本空间受控对象；存储路径不进入输出 |
| AuditEvent | id、actor_id、workspace_id、action、target_id、result、created_at | 关键写入与审计在同一数据库事务中保存 |

核心查询为账号唯一查询、会话摘要、空间成员、空间内模型/数据集列表、数据集版本、审计时间序列，建立对应索引。API 必须带空间范围筛选，不能读取后只在前端隐藏。

更新模型、数据集、用户组等可变元信息采用 revision 与 If-Match；实际 UPDATE 同时限定旧 revision，避免并发覆盖。不可变版本不提供修改文件内容的 PATCH。

管理员禁用或降权涉及跨账号约束。SQLite 先取得管理员集合的写锁，再检查剩余启用数量；PostgreSQL 按固定顺序对管理员行加锁。检查与修改在同一事务内完成。当前回归以 SQLite 为准，正式数据库的并发集成仍列入上线验收。

## 权限计算

权限集合先合并组允许和个人允许，管理员加入平台角色允许，再排除组或个人显式禁用。最后检查空间成员和成员角色；viewer 即使具有组写权限，也不能在该空间写资产。管理员在无显式禁用时可管理全部空间。管理账号和组的接口还要求平台管理员身份。

初始部署只有显式初始化的管理员。普通用户由管理员创建并配置组及空间，默认没有越过空间边界的权限。有效配额只返回计算结果，不允许用户在创建作业时传入另一套“有效权限”。

## 后续训练模型

训练项目组织多次实验。任务保存不可变 ConfigSnapshot，ExecutionRecord 保存派发与执行事实，ResourceAllocation 独立跟踪预留、使用和释放。用户改参或重跑创建新任务并关联来源；传输重试和产物重传保留原任务。

| 状态 | 后续状态及条件 |
| --- | --- |
| 草稿 | 提交中或放弃 |
| 提交中 | 校验失败回草稿；受理成功排队中；受理后实际失败/取消按事实记录 |
| 排队中 | 实际启动确认后运行中；永久错误失败；取消核查完成后已取消 |
| 运行中 | 停止请求已受理进入停止中；执行和必要产物满足要求后成功；故障失败 |
| 停止中 | 结束和清理有证据后已停止；独立执行错误失败；超时仍保持待核查 |
| 成功、失败、已取消、已停止 | 终态不重置，重跑创建新任务 |

环境准备、权重下载和产物上传为执行阶段。任务失败不直接证明资源已释放；失联和停止超时均不允许另派相同执行。

## 后续辅助模型

ExternalModelConnection 保存服务端凭据引用、能力和限额；AssistantRequest 固定输入范围、版本、授权与提供商；AssistantResult 保存候选、证据和有效条件；AdoptionRecord 记录用户确认及新对象。

辅助授权绑定输入摘要、关联版本、使用目的、提供商和确认人，改变任一关键条件需重新核查。日志片段、图片样本和配置统计按授权保存必要引用；秘密信息不进入内容记录。模型输出不能自行写审计“成功”或标记任务已结束。

M1 只实现上表中的实际基础对象。训练、资源分配与辅助表随对应规范和迁移增加，不创建没有消费方的空业务表。
