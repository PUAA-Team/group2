# Worker 与智能辅助协议

本文件为后续计算与模型 API 实现的设计基线，M1 不提供模拟成功端点。

## Worker 身份与生命周期

管理员生成限时、一次性接入凭据，Worker 主动注册并报告设备、显存、CPU、运行时及能力。审核通过后签发独立可撤销凭据。设备身份使用稳定标识，不仅使用本机序号。

Worker 主动向控制端心跳、领取任务、读取停止意图和上报事件。网络只要求节点能主动访问平台；正式部署使用 TLS。凭据用途分离，不把接入令牌拼入可共享的命令或截图。

注册、心跳、领取、续租、回传和结束消息分别携带 protocol_version、node_id、请求标识与时间。执行消息还包含 execution_id、assignment_id、lease_id、单调序号和配置快照摘要。

## 派发与事件

1. 任务服务可靠保存配置快照和排队记录，再返回受理。
2. 调度器按设备、显存、运行时、任务类型、授权和额度硬过滤，之后按优先级及受理时间排序。
3. 预留与唯一指令创建在事务内完成。Worker 重复领取返回同一有效指令，不增加第二个训练。
4. Worker 准备环境和文件，实际启动后回传事实。准备不被显示成已运行。
5. 事件包含执行号、序号、源时间、接收时间、类型、阶段和数据摘要；重复和迟到事件核查后保存。
6. 必要产物上传并通过清单、大小和摘要校验后，任务才可成功。资源释放由独立证据确认。

心跳超时、租约到期或控制端重启均不证明原进程已经结束。停止新派发、保留占用并核查，避免在另一个节点重复运行。检查点恢复只对已验证兼容的训练器开放，重跑另建任务。

监控订阅按工作空间授权，前端使用游标断线续传。浏览器断线不停止训练。缺失指标使用未知状态，不能用零值或模拟曲线补齐。

## 模型网关

提供商适配器输入统一请求，返回候选内容、模型标识、用量、结束原因和提供商请求标识。文本、图像、JSON Schema、流式输出和工具调用分别登记能力；不假定协议兼容即功能相同。

连接配置包含批准的地址、能力和限额；秘密仅保存在服务端凭据存储中。调用前验证用户、空间、连接、输入范围、脱敏结果、预览授权、剩余预算及版本。扩大输入、改变目的或提供商后重新确认。

API 超时、鉴权错误、限流、预算不足、取消或结构错误只影响该辅助请求。重试有上限，未知调用结果先核对；不偷偷切换未授权提供商。保留人工配置和标注路径。

## 结果与采纳

参数建议输出允许字段、原值、新值、理由和依赖条件；服务端再次检查类型、范围、训练器及资源约束。标注输出样本标识、候选标签及对应任务结构；模型自报分数不当作已校准置信度。日志解释输出证据引用、事实、推测和排查步骤。

候选关联固定输入版本和提示词版本。用户可以部分采纳或拒绝；采纳事务复核权限和输入版本，并创建独立配置或数据版本。重复采纳返回既有结果，旧候选不能覆盖新修改。训练运行参数不受采纳动作原地修改。

原始日志、检索结果和样本作为数据，不获得工具执行权限。模型不能直接调用主机命令、改变角色、删除文件或开通付费资源。

## 后续 Agent 复用

Agent 工具调用同一应用服务，持久状态保存步骤和操作回执，审批绑定具体动作及参数摘要。记忆按工作空间、来源、有效期及撤销状态管理；实时任务和配额通过业务服务查询。协议层和 Agent 框架不承担领域授权。
