## 恢复上下文的阅读顺序

先读本页和实施进度，再读对应规范、API 与数据约定。开始下一项工作前核对代码和测试结果，禁止仅凭历史对话判断完成。

当前 8765 前端继续作为独立演示。真实后端另用本机 8000 端口；联调时显式选择真实数据源，失败不能退回模拟结果。所有运行数据、虚拟环境、下载、日志和测试缓存放 D 盘，代码和设计文档保留在项目。
