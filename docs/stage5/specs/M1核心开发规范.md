# M1 核心开发规范

状态：本批实现完成，本机 34 项回归通过；代码、证据及剩余限制见[实施记录](../实施进度与交接.md)。后续修改仍先更新约束与复现测试。

## 身份与授权

提供显式管理员初始化、登录、当前会话、退出、用户和用户组管理。密码使用随机盐 scrypt，摘要比较使用常量时间方法。返回 DTO 不包含 password_hash、token_digest 或原始凭据。错误登录限制必须存在，过期和禁用即失效。

所有状态修改除登录外都校验 CSRF；登录校验来源和 JSON 类型。用户/组管理仅管理员可用，创建普通用户不默认赋予平台管理员权限。防止禁用最后一个有效管理员。

有效权限按组与个人允许并集减去显式禁用，再核查空间角色。配额采用组与个人较小值，个人缺失则继承。列出和读取资产都限定空间，不仅在写入时鉴权。

验收包括：错误密码、未知账号、限流、无会话、过期、退出、禁用、缺失/错误 CSRF、外部 Origin、个人禁用、组禁用、只读角色、非成员和跨空间标识替换。

## 模型资产

获授权成员登记模型并绑定受控模板；模板至少列出三条一期路线，执行状态在训练器接入前不可用。登记不下载或执行 source_ref，未知任务和不匹配模板返回明确错误。模型资产有 revision；版本号唯一，版本内容不可变。

验收包括：创建、跨会话读取、分页、权限拒绝、错误模板、带凭据来源、重复版本和过期 If-Match。不得通过输入 status 或 owner_id 改成已验证模型或伪造他人资产。

## 数据资产

登记数据集后允许获授权成员上传支持格式。文件写入受控暂存目录，服务端解析并计算数量、大小及摘要；全部校验成功后形成不可变版本。空标签文本可待标注，但不能标记可训练。输入异常不得产生可用版本或泄漏磁盘路径。

验收包括：CSV、JSONL、空文件、错误编码、缺字段、空文本、破损 JSON、过大文件、不支持的图像归档、名称路径穿越、跨空间上传和预览、旧版本保留及创建后重启读取。

模型/数据元信息更新携带 If-Match，缺失 428，过期 412；真正的 SQL 更新也必须检查 revision，避免并发读写绕过。

## 存储与运行

请求会话独立，业务变更与审计同事务。应用不在导入或启动时创建账号、自动建表或重置数据。迁移和初始化通过显式命令执行；配置路径、数据库与存储根均可替换。

SQLite 仅作本机联调和测试；保持 PostgreSQL 可迁移结构，正式数据库集成另行验证。M1 不假装已完成真实调度、训练、推理或付费 API。

测试使用 D 盘隔离文件，关键测试失败即停止后续交付。完成后导出运行应用 OpenAPI，核对本规范、API 表、实现及测试均可定位。
