## 已确认

- 一期三条真实训练路线、页面资产维护和三项智能辅助。
- FastAPI 模块化单体、独立 Worker、`/api/v1`；现有演示不覆盖。
- D 盘独立 Python 环境及批准的基础依赖；训练依赖另行确认。
- SQLite 先作本机联调，正式 PostgreSQL；本轮不装数据库系统服务。
- 外发采用工作空间授权与脱敏预览确认，本轮不外发真实数据或调用付费模型。
