# 一期开发计划与验收

## 范围与顺序

M0 完成设计、API 和规范；M1 先建立真实账号、工作空间、权限及资产数据。M2 打通计算执行和外部模型，M3 联通三条训练路线与智能辅助，M4 完成故障、安全和部署验收。

本机先用 SQLite 联调和测试，SQLAlchemy 隔离数据库访问；正式部署采用 PostgreSQL，切换前必须执行迁移和并发集成测试。SQLite 联调通过不代表多调度器或跨进程资源争用已经验收。

| 工作项 | 交付物 | 完成条件 |
| --- | --- | --- |
| D01 设计基线 | 架构、数据、API、Worker/辅助协议、规范及索引 | 所有约定可定位，待实现项明确 |
| B01 运行骨架 | 配置、事务、错误处理、健康与就绪检查、迁移 | 不自动创建账号或修改已有数据库；运行数据在 D 盘 |
| B02 账号与会话 | 初始化管理员、登录、会话、退出、账号启停 | 密码和会话明文不落库；禁用立即失效；错误不泄露凭据 |
| B03 空间与权限 | 用户组、个人允许/禁用、空间成员、有效配额 | 显式禁用优先；配额取较小值；对象访问防越权 |
| B04 模型登记 | 三类任务模板、模型资产及版本 | 模型来源只登记，校验状态真实，不自动下载或执行代码 |
| B05 数据资产 | 数据集、真实文本文件上传、不可变版本和样本统计 | 文件解析和持久化真实，错误文件不产生可用版本 |
| B06 契约与交付 | OpenAPI、单元/接口测试、启动与备份说明 | 实现与契约一致，测试可重复，未完成能力明示 |
| C01 计算执行 | Worker 注册、心跳、领取、事件和产物、调度 | 真实 CPU/单 GPU 作业，幂等派发、释放有证据 |
| A01 模型网关 | 连接、权限、能力、预算、预览授权与结果记录 | 只调用获准模型，服务端存凭据，失败不影响普通流程 |
| A02 智能标注 | 样本工作区、预标注、复核、发布 | 文本/图片分类真实候选可编辑，发布保留版本来源 |
| A03 参数推荐 | 上下文、建议差异、校验、采纳 | 生成新配置，不修改运行任务，过期及重复确认正确处理 |
| A04 日志解释 | 真实日志片段、故障证据、解释与修订入口 | 事实和推测分开，证据可定位，不执行任意命令 |
| T01 三条训练路线 | 文本、图像和 Qwen LoRA 训练器 | 各有固定样本、真实指标、产物和对应推理验证 |
| R01 稳定性与上线 | 失联/重启/停止/配额争用/外部超时测试、Linux 部署 | 业务状态与清理分开，未知执行不会重复派发 |

B01 至 B06 为本次第一批实现。现有前端的页面改造另按联调批次推进，保持已确认的样式；本批不新增业务界面。

## 测试要求

优先写无网络的权限、版本和状态测试，再写 HTTP 接口及数据库集成测试。出现错误先保留复现用例，修复后运行回归。第三方 API 测试替身只用于协议与错误处理，不作为已接入真实模型的证据。

M1 至少覆盖：未登录、错误密码、暴力登录限制、会话过期/退出/禁用、CSRF、非成员访问、只读成员写入、个人/组显式禁用、个人配额继承及较小值、跨空间资产访问、冲突更新、损坏/过大/重复文件、不可变版本、重启后持久化与错误脱敏。

任务执行增加：重复提交、无可用资源、准备失败、实际启动确认、取消/派发竞争、运行停止、失联保留占用、产物失败重传与控制端恢复。辅助增加：无授权、扩大输入范围、预算不足、超时/限流、非法结果、部分采纳、结果过期与重复确认。

质量指标分别记录接口与格式合格率、人工标注修改量、建议可执行性、日志证据正确性、任务和资源恢复结果。固定参考集确认后再设置业务效果阈值，不预填准确率、性能提升或训练结果。

## 一期之外

新任务类型、用户训练器插件、任意代码执行、云端高级接入入口、SSO、多组织商业计费、Agent 记忆和工具编排后续安排，集中记录在[后续功能待办](../后续功能待办.md)。一期保留训练器、计算、模型提供商和存储接口，避免提前建设插件平台。

## 持续交接

每完成一项，在[实施进度](./实施进度与交接.md)登记实际代码、测试、运行命令和限制。未完成项保持未完成；不得用演示数据补充真实接口结果。每个阶段同时更新本索引、规范及运行说明。
