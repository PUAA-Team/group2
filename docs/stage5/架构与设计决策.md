# 平台架构与设计决策

## 逻辑架构

接入层包含 FastAPI HTTP、后续监控订阅和 Worker 协议。应用服务层负责账号、空间、权限、数据、模型、训练、资源、评估/推理及智能辅助。调度执行层包含持久队列、调度器和独立 Worker。数据层保存关系对象、文件、事件、版本、审计和辅助调用回执。

页面 API、一期智能工作流和后续 Agent 工具都调用应用服务。业务授权、版本检查和资源约束只维护一套。路由处理输入、认证和响应；应用服务编排事务；基础设施适配 SQL、文件、计算和模型提供商。

```text
页面 API / 辅助工作流 / 后续 Agent 工具
                     |
              统一应用服务与权限
     身份 空间 数据 模型 任务 资源 评估 推理 辅助
                     |
       关系存储 文件存储 计算后端 模型提供商
                              |
                       独立 Worker/训练器
```

## 代码组织

真实后端放在 `backend/src/model_platform`。配置、数据库、错误、安全与权限保持独立；`api` 按功能拆路由；`services` 按业务拆事务；训练、计算和模型网关后续分别增加适配模块。`backend/tests` 保留可重复测试，迁移放 `backend/migrations`。不改动既有文档生成脚本和前端样例。

每次请求独立数据库会话，事务要么完整提交，要么回滚。跨模块通过应用服务及标识交接，不共享会话单例和可变全局业务字典。FastAPI 应用通过工厂创建，测试可以注入隔离配置和存储路径。

M1 简单登记接口调用共享权限、版本、提交及审计函数组织单次事务；文件解析和保存补偿已在 services 中独立实现。后续训练和智能辅助在各自应用服务中编排，由页面和工具入口共同调用。该分层随真实使用方完善，M1 未创建尚无调用者的 Agent 框架。

## ADR01 模块化单体

背景是内部团队规模和现有单一前端，需要先建立一致的权限、资产与训练模型。选择一个 FastAPI 产品后端，训练由独立进程承担。模块提供明确职责，但不提前增加微服务部署、分布式事务或服务发现。

后果是早期部署简单，模块内仍须隔离路由与业务逻辑；计算负载通过 Worker 扩展。后续拆分以实际负载和管理边界为依据。

## ADR02 数据库与文件

正式部署采用 PostgreSQL；本机按已确认方案先用 SQLite 持久化联调。使用 SQLAlchemy 2.x，避免路由依赖某种数据库的 SQL 字符串。迁移通过 Alembic 显式执行，应用启动不静默建表。

SQLite 开启外键并使用文件数据库，测试使用独立临时目录。数据库连接和所有文件位置从配置取得。SQL 类型、JSON、UTC 时间和并发更新须兼容 PostgreSQL；正式迁移、行锁与多调度器争用另作 PostgreSQL 验收，不以 SQLite 测试代替。

文件先保存到 D 盘受控根目录。随机对象路径由服务端生成，用户文件名只作展示，不能拼入存储路径。上传暂存、解析、校验、入库有明确失败补偿；进程异常遗留文件通过后续带宽限期的清理流程处理。

## ADR03 会话与权限

浏览器使用服务端会话和 HttpOnly Cookie，不使用原型中的本地密码摘要或演示身份。会话凭据为高熵随机值，数据库只存摘要。Cookie 默认 SameSite=Strict；开发仅绑定回环，Linux HTTPS 启用 Secure。状态修改必须验证 CSRF；跨域只允许配置中的精确来源。

平台角色暂为管理员和成员。组授权与个人允许合并后排除任一显式禁用，再检查工作空间、操作和对象范围。管理员的范围权限不取消显式禁用规则。非管理员不能通过传入管理员标识、别人的 ownerId 或替换 workspaceId 提权。

个人配额未设时继承组上限，已设时取两者较小值；实际调度还需扣除已用及预留。M1 实现有效策略计算，资源预留与并发扣额在计算阶段实现并测试。

## ADR04 先建立真实能力

模型目录、数据格式和训练器能力分开登记。M1 的模型登记不自动下载权重、不启动训练，也不能将用户传入的“已验证”当作实际执行证据。三条任务模板提供受控契约，训练器在后续通过真实验证后启用。

现有演示前端继续运行在 8765，真实页面与后端同源使用 8000。stage6 已接入身份、空间和资产；API 错误明确反馈，不退回模拟指标、模拟探测或模拟服务响应。

## ADR05 智能辅助和后续 Agent

一期辅助采用确定性业务工作流：构造获准上下文、调用模型、验证结构及业务内容、展示候选、人工确认、创建新对象或版本。模型网关只处理提供商差异，不能代替权限、预算和任务状态规则。

后续工具目录复用应用服务，记忆关联空间、来源、有效期及撤销信息，运行时状态从实时业务服务查询。Agent 库和 MCP 作为适配层后续选型，本期不安装或建立空泛的通用插件平台。

## 安全与审计

密码使用带随机盐的 scrypt 派生，校验采用常量时间比较；账号禁用后会话立即失效。生产首次管理员通过部署 CLI 创建，本机也可显式开启仅回环可访问的网页设置；同样只允许初始化一次，不内置通用初始密码。登录限制、跨空间访问和管理员操作都要测试。

审计仅保存动作、主体、目标、结果及必要的变更摘要；密码、Cookie、CSRF、模型密钥、上传原文不得写入错误和审计。请求错误统一返回稳定业务代码和请求标识，服务端异常不向客户端输出堆栈或数据库连接信息。

## 参考
