# 第二阶段交付说明

## 本阶段完成内容

前端已有登录注册、两级可折叠菜单、用户端十二个主要页面和管理端八个页面。用户端新增用户空间、资源监控、在线标注、数据增强、模型评估与 API KEY 管理；原有数据集、训练、模型、服务页面继续可操作。管理端扩展了统计、节点接入、资产与作业视图、用户组和个人权限、操作记录及系统设置。

训练目录新增 Qwen2.5-0.5B-Instruct 的文本分类与指令微调演示项。资源管理可复制不可执行的示意命令，登记节点并模拟自动探测。所有新增数据仍保存在本地浏览器；没有新增后端接口、训练进程、GPU 代理或真实鉴权。

## 验证记录

- Node 自动测试：12 项通过，覆盖已有训练闭环、页面渲染、角色菜单、组与个人权限合成、配额计算、GPU 模拟接入及增强策略过滤。
- 浏览器检查：管理员演示登录后，抽样访问工作台、数据集、新建训练、模型仓库、资源管理、用户管理；在 1280px、768px、390px 三种视口验证标题与页面级横向溢出，共 18 组检查通过。另对 15 个页面入口做桌面路由检查，并验证普通用户看不到管理菜单、直接访问管理地址得到无权访问结果。
- 发现并修复模型卡片标识与数据表格同名样式类造成的手机横向溢出；先加入可复现的浏览器断言，再修改并复测。

当前浏览器检查覆盖页面级布局，尚未逐项完成所有鼠标、键盘与真实文件输入的人工验收。测试数据与真实能力缺口见[后续功能待办](../后续功能待办.md)。
