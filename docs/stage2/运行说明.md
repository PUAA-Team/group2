# 第二阶段运行说明

本阶段是静态前端，无需安装依赖、编译或 Docker Compose。在项目根目录启动本地页面服务：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

随后打开 `http://127.0.0.1:8765/`。停止服务时，在启动服务的终端按 `Ctrl+C`。

登录页可直接点击“管理员”或“普通用户”演示入口。手工输入时，管理员账号为 `admin@example.test` / `Admin123!`，普通用户账号为 `lin@example.test` / `Demo123!`。也可在注册页新建普通用户。**这些凭据只用于本地演示，请勿复用真实密码。**

在 `frontend` 目录运行自动测试：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --test --test-isolation=none
```

数据保存在浏览器的 `localStorage`，会话登录标识保存在 `sessionStorage`。需要回到初始示例时，可在浏览器站点设置中清除 `127.0.0.1:8765` 的站点数据，然后刷新页面。清除站点数据会移除在本演示中新增的账号、任务、用户组与密钥，操作前请自行留存需要的信息。

管理端“接入新节点”的命令仅是不可执行的占位文本；复制功能用于评审交互。不要把它粘贴到真实服务器执行。
