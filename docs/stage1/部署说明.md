# 第一阶段运行说明

## 直接打开

在浏览器打开项目中的 `frontend/index.html`。页面通过 JavaScript 模块加载；若浏览器限制本地文件模块访问，请改用下面的本地服务方式。

## 本地服务

在项目根目录运行：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

打开 `http://127.0.0.1:8765/`。停止服务时，在运行命令的终端按 `Ctrl+C`。当前版本无安装、编译或后端部署步骤，也不依赖 Docker Compose。

## 自动测试

在 `frontend` 目录运行：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --test
```

测试只读取前端模块并验证本地演示状态。页面中的数据保存于浏览器 `localStorage`，键名为 `model-training-demo-v1`；清除该站点的本地存储即可恢复初始示例数据。请勿把浏览器示例数据作为真实业务数据使用。
