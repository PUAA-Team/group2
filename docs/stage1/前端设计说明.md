# 第一阶段前端设计

## 定位与范围

本阶段交付一个可独立运行的纯前端演示版，用于确认平台的信息架构、训练配置流程和页面交互。功能组织参考飞桨 BML 调研中的数据准备、项目训练、模型管理、服务发布与管理入口，并按当前需求把“任务类型 → 模型/网络 → 数据集 → 参数与资源”作为训练主线。界面未绑定特定云厂商。

本阶段只使用浏览器本地状态与预置示例数据，不连接后端、存储服务或计算资源。所有模拟行为及后续实现事项集中记录在[后续功能待办](../后续功能待办.md)。

## 信息架构

左侧固定导航分为工作入口和管理入口。工作入口包括工作台、数据集、训练项目、训练任务、模型库、推理服务；管理入口包括资源管理、用户权限、操作记录。桌面端保持侧栏固定，窄屏改为可关闭的抽屉导航。

数据集按图像、文本、表格组织；每个任务对应格式说明、示例模板和处理选项。训练配置使用四步向导，先确定项目、任务和训练方式，再选择兼容数据集，最后配置参数与资源并核对。任务详情提供概况、指标、日志和产物四个视图。已完成任务可以进入推理服务创建流程。

模型目录目前覆盖以下任务，模型和网络选项在 `frontend/js/data.js` 中集中配置，新增任务可按相同数据结构扩展页面选择项：

| 数据类别 | 任务 | 预置模型示例 | 网络训练示例 |
| --- | --- | --- | --- |
| 图像 | 图像分类、目标检测、实例分割 | MobileNetV3、YOLOv8n、Mask R-CNN | ResNet18、YOLOv8n 网络、U-Net 网络 |
| 文本 | 文本分类、短文本相似度、实体抽取 | 中文 BERT、Sentence-BERT、BERT-CRF | TextCNN、双塔网络、BiLSTM-CRF |
| 表格 | 二分类、多分类、回归预测 | XGBoost 系列 | 多层感知机 |

## 视觉与交互约束

采用中性灰底、白色内容卡片、蓝色主操作及少量状态色。字号、圆角和边框保持统一；不使用装饰性大面积渐变和冗长说明。小屏时信息卡片改为单列，表格在自身区域横向滚动，训练步骤完整展示。界面上的“演示”字样用于避免将模拟结果误认为真实训练和推理。

页面由原生 HTML、CSS、JavaScript 模块构成。`data.js` 维护任务定义与示例数据，`state.js` 负责演示状态，`pages/` 按业务页面拆分，`app.js` 负责路由与交互。没有新增第三方前端依赖。
