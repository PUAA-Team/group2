# Stage 17A 与 Stage 18A 实施与验收

## 完成范围

### 1. Stage 17A：统一默认文件存储与受控模型权重上传
- **统一存储边界**：新增 `backend/src/model_platform/services/file_storage.py`（`resolve_key`、`write_atomic`、`read_verified`、`delete_object`），统一数据集版本、训练产物、模型上传权重及资产物理删除的文件读写与 SHA-256 校验路径。
- **受控模型权重上传**：
  - `ModelVersion` 新增 `storage_key`、`sha256`、`size_bytes` 字段，迁移文件为 `0013_model_storage`（`backend/migrations/versions/0013_model_version_storage.py`）。
  - 新增 `POST /api/v1/workspaces/{workspace_id}/models/{model_id}/versions/upload`，使用 `validate_artifact` 校验 `.zip`（必须包含 `manifest.json` 与对应训练器的 `safetensors` 头部），写入空间配额账目并落盘。
  - `jobs.py` / `executions.py` 支持 `upload://...` 受控权重进入推理服务与 Worker 下载校验。
- **前端界面**：模型详情页（`frontend/live/pages/assets.js`）新增“上传权重”按钮与“文件大小”列，`dialogs.js` / `events.js` 接入受控权重 `FormData` 上传弹窗。

### 2. Stage 18A：控制台补齐与导航修复
- **工作台待处理事项**：`overview()` 新增 `pending_items`（待审批加入申请、进行中标注批次、失败训练任务）；`frontend/live/pages/overview.js` 在工作台展示“待处理事项”摘要条。
- **用户空间个人任务**：新增 `GET /api/v1/workspaces/{workspace_id}/my-jobs`，用户空间页面展示当前登录成员的“我的近期任务”。
- **数据集标签分布与校验报告**：新增 `GET /api/v1/workspaces/{workspace_id}/datasets/{dataset_id}/versions/{version_id}/report`（返回样本数、空标签数、文件大小、SHA-256 完整性及标签分布占比）；数据集详情页增加“校验报告”按钮及只读弹窗。
- **统计面板筛选维度**：`GET /api/v1/admin/statistics` 支持 `creator`、`created_from`、`created_to` 查询参数，前端管理端 `/admin/stats` 工具栏接入 `filterControls(ctx)`。
- **导航修复**：在 `frontend/js/ui.js` 的 `NAV_GROUPS` 概览分组补齐 `["智能辅助", "/assistants"]`，`pageTitle("/assistants")` 正确返回“智能辅助”。
