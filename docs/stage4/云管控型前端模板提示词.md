# 云管控型前端模板提示词

本模板用于模训平台的完整前端。采用已确认的云管控型导航框架、深青绿主操作、蓝色详情入口和适度圆角，用户端、管理端、登录注册共用同一套组件规则。后续新增页面和组件沿用以下提示词。

## 可直接复用的提示词

请为一个面向模型训练与计算资源管理的平台设计并实现前端。产品包含数据集、标注、数据增强、训练项目、训练任务、模型仓库、模型评估、在线服务、API KEY，以及管理员的资源、用户组、权限、作业和审计管理。保留既有业务能力、路由、本地演示数据与操作流程。

整体采用紧凑、克制的云管控界面。重点是清楚的导航、可扫描的列表、稳定的操作位置和一致的组件尺寸。以真实云控制台的布局与密度为参考，品牌使用本平台自己的名称、标识和配色。

### 框架和导航

顶部为高 50px 的深灰色全局栏，背景 #22252b，放平台名称、工作空间和账号操作。左侧是固定的浅灰导航，背景 #eaedf1，宽 208px，右侧仅保留细边界线。主体画布为 #f4f5f7。

导航分一、二级，菜单行高 34px、字号 14px。一级包含图标、名称和展开箭头；二级使用缩进。当前位置用浅色底和文字颜色区分，二级左侧不加竖条。五个用户功能分组首次全部展开，保存用户手动展开、收起的状态。管理员入口独立分区，仅对管理员显示。

左侧导航可用鼠标滚轮、触控板和键盘滚动，隐藏长条滚动条。切换路由、打开弹窗和改变筛选条件时，保持导航滚动位置。菜单整体收窄为 64px 后，只保留一级和管理入口的图标及必要控制按钮；隐藏全部菜单文字、二级列表、分组标题和箭头。图标保留可访问名称与悬停提示。再次展开时，恢复原来的分组状态和滚动位置。

手机端导航改为抽屉，打开后显示完整菜单，点击遮罩或关闭按钮收起。桌面收窄状态不影响手机抽屉的完整显示。

### 配色和文字层级

主色为深青绿 #276d62，悬停加深为 #205b52。主色用于主操作按钮、选中导航、当前标签、输入焦点和少量关键曲线。每个页面应有明确的主要操作，其余操作使用白底、灰边或文字按钮。

主体采用中性色。普通标题和文字用 #252525 至 #30363d，正文用 #515862，辅助信息用 #737780，边界用 #e3e5e8。可进入详情的任务、数据集、项目、模型和服务名称用蓝色 #1664c0、600 字重，悬停加深并出现下划线；普通操作链接同属蓝色体系。静态名称保持黑灰，避免暗示不存在的点击行为。统计数字、分类图标和普通组件不统一染成主题色。

成功状态为绿色 #228443，运行状态为蓝灰 #3d718a，等待和维护为赭黄 #a4660c，失败与危险操作为红色 #bf3028，停止和停用使用灰色。这些颜色只承担相应业务含义。图表可使用一条深青绿主曲线和一条灰色虚线辅曲线，利用线型、名称共同区分。

中文字体优先使用 Microsoft YaHei UI、PingFang SC。正文、表头、字段、标签、菜单和操作均不低于 14px；页标题 22px，分区标题 16px。数字与名称左对齐，必要的数值比较按列对齐。长名称适度换行或截断并提供完整内容，避免单个汉字被挤到下一行。

所有页面删除解释性小字，尤其避免“大标题加灰色说明”“名称加小号第二行”“大数字加解释备注”的组合。配额合成规则、操作说明和重复导语放到文档中；卡片不附加数据格式长描述。任务类型、版本、训练方式等短信息可使用 14px 标签框。邮箱、模型等有业务价值的信息使用明确表格列或正常字号字段。错误、必填限制、安全警示与格式模板按正常字号显示。

### 面板与边角

页面按业务内容分区。标题、标签、搜索和筛选可直接放在画布上；表格、曲线与表单使用各自的白色区域。统计项共用一条白色汇总区，内部使用分隔线。避免把整页内容统一包进一个大边框，也避免给每段文字或每项指标分别套卡片。

项目、模型、资源等独立实体可以使用卡片：白色内容区，底部操作或附属信息使用浅灰 #f6f8fc，通过细线分隔。卡片之间有 16px 留白，卡片内不再套小卡片。普通区块边界 1px、圆角 8px、内部留白 20px；基础按钮、输入框、选择框使用 6px 圆角；弹窗使用 10px。一般面板没有阴影，卡片悬停和弹出层可使用轻阴影。圆形用于状态外圈与步骤编号，避免把普通控件做成胶囊。

禁用装饰性渐变、玻璃效果、发光、大数字背景和非交互的浮动动画。

### 列表和状态

表格正文与表头均为 14px，标准单行约 58px。名称、邮箱、模型、任务类型和操作分别放在对应列中，避免名称下再堆叠一行小字。表头使用很浅的灰底，行之间有细分隔线，悬停为浅灰底。宽表格在自身容器中横向滚动，保持文字可读。

所有状态使用圆形外圈加内部符号：运行用播放符号，完成用勾，等待用时钟，失败用叉，已停止用方块，已取消用斜线，停用用横线。颜色与符号共同表达状态。

列表、表格和资源列表中仅显示状态图标，默认隐藏状态文字。鼠标悬停或键盘聚焦时显示完整的中文状态提示；按 Esc 可关闭提示。提示层应避开视口边缘，能完整显示在表格滚动区域之外。图标保留无障碍名称，触控可点按查看。详情标题、执行记录等需要直接理解上下文的位置可显示图标与状态文字。

搜索、筛选、数量统计位于列表上方，常规操作位置一致。宽表格在自己的容器中横向滚动，禁止造成整页左右滚动。空列表保留清楚的空状态和必要操作，不填充无关说明。

### 表单、弹窗和流程

按钮、输入框、选择框标准高度为 32px。按钮及行内操作文字均为 14px。输入框为白底灰边，具有统一的悬停、聚焦、错误和禁用状态；选择框有明确箭头，保留键盘选择行为。参数范围通过输入约束与明确错误反馈呈现，输入框下不附加小号范围说明。

新增用户、用户组、权限配置、节点登记、API KEY、服务创建、系统设置、数据处理和增强配置使用弹窗。弹窗默认约 600px，复杂权限配置约 760px；标题、内容和底部操作分区，内容超高时内部滚动。避免在列表中直接展开新增或编辑表单。删除和危险操作保持独立的警示层级。

新建训练保留四步独立页面：任务与模型、数据集、参数与资源、核对提交。导入数据集保留独立页面，包含任务选择、文件预览与格式模板。复杂流程使用页面级布局，已填写的数据在步骤间保持。

登录注册沿用同一字体、主按钮、表单和圆角。页面保持简洁，普通用户可自主操作，不写冗余导语、重复总结或功能说明书。真实错误、格式限制、敏感操作和演示边界应在需要的位置明确提示。

### 实现与验收

优先复用公共导航、状态、表单、按钮、弹窗和表格组件。主题参数集中定义，避免单个页面独立造一套样式。保留路由、功能权限、用户组、个人权限、配额和本地存储规则。

至少检查 1440px 桌面、1024px 窄桌面和 390px 手机布局。逐页检查导航、表格、选择框、弹窗、长名称、训练向导与导入流程；验证菜单折叠后无残留文字、切换菜单不跳回顶部、状态文字仅按规则显示。区分真实功能与前端模拟行为，模拟训练和节点接入继续保持明确标识。

## 当前实现位置

完整原型入口是 `frontend/index.html`，本地地址为 `http://127.0.0.1:8765/#/home`。公共样式位于 `frontend/styles`，导航与状态由 `frontend/js/ui.js` 提供，状态提示由 `frontend/js/status-tooltip.js` 提供。独立视觉审查样例继续保留在 8766 端口，历史外观试选不影响完整原型的固定方案。

菜单折叠实现需特别检查选择器优先级：隐藏规则覆盖“已展开分组”的显示规则，手机抽屉再显式恢复完整菜单。保留菜单滚动本身，隐藏的只是可见滚动条。
