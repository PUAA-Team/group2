# 云管控型完整原型迁移与运行说明

## 本次迁移

完整原型采用云管控型导航、深青绿主操作和适度圆角。迁移包含全部用户端与管理端、登录注册、详情页、训练四步向导、数据导入及配置弹窗。既有数据结构和本地演示流程保持不变。

主体文字、统计数字、分类标识和普通组件使用中性色；可进入详情的名称使用加粗蓝色。标题、筛选和标签保持开放布局，表格、曲线和表单按区块使用白色面板；独立实体卡片使用白色内容区与浅灰底部区域。面板、控件、弹窗圆角分别为 8px、6px、10px。

状态独立使用绿、蓝灰、赭黄、红和灰。列表状态只显示圆形图标，悬停、聚焦或点按显示状态文字，详情保留必要文字。侧栏与页面保留滚动，隐藏可见长条滚动条；侧栏收窄时隐藏全部菜单文字与二级列表。

可复用规则见[模板提示词](./云管控型前端模板提示词.md)。本阶段属于前端视觉迁移，文档目录中的 stage4 不代表软件工程课程阶段划分。

全部文字样式不低于 14px。解释小字、卡片格式描述、统计备注和标题下的重复介绍已删除；任务类型、版本和训练方式采用标签。邮箱、模型等有效信息改为独立列或明确字段，安全警示和错误反馈保持正常字号。

## 启动

在仓库根目录打开 PowerShell：

```powershell
& 'C:\Users\lixu\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8765 --bind 127.0.0.1 --directory frontend
```

浏览器访问 `http://127.0.0.1:8765/#/login`，点击“管理员”或“普通用户”进入演示。服务已运行时直接使用原地址。端口只绑定本机，不需要安装依赖、Docker 或修改环境变量。终端按 Ctrl+C 可停止本次服务。

原型沿用浏览器本地数据和菜单分组偏好。不同来源地址 `localhost` 与 `127.0.0.1` 的数据分别保存；演示登录会话按标签页保存，新标签页可能需要重新点击演示账号。不要为切换样式清空浏览器存储。

独立审查样例仍位于 `http://127.0.0.1:8766/cloud-v2/`，用于保留之前的配色对照，不是完整原型入口。

## 功能边界

本次调整没有增加后端能力。文件上传仅做本地预览和登记；训练、曲线、资源探测、模型评估、服务调用、密钥与配额仍是前端演示。真实训练和资源接入等工作继续记录在[后续功能待办](../后续功能待办.md)。

本轮没有安装依赖、修改全局环境、清空本地数据或覆盖历史视觉样例。原始业务组件继续复用，界面使用新的统一外观。

## 版本与恢复

当前入口、样式和模块统一使用 `console-4` 缓存版本。主体二次调整前的代码备份为[console-2](./备份/前端模板_console-2.zip)，小字清理前的备份为[console-3](./备份/前端模板_console-3.zip)。各备份包含当时的 js、styles 和 index.html，不包含浏览器数据或依赖。恢复时先解压到新目录，核对文件，再将需要的部分放回 frontend 下的对应位置。恢复代码不需要清空浏览器数据。
