# 大模型集成训练平台前端原型

本压缩包包含当前完整前端原型的页面代码、样式和本启动说明。使用现代浏览器和 Python 3 即可运行，无需安装前端依赖、数据库或 Docker。

## 启动方法

1. 完整解压压缩包，进入 `model-training-prototype` 文件夹，确认当前目录中有 `index.html`、`js` 和 `styles`。
2. 在该目录打开终端，启动本地静态服务。

Windows PowerShell：

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1
```

如果电脑通过 `python` 命令运行 Python 3，也可以使用：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

macOS 或 Linux：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

3. 保持终端运行，在浏览器打开：

   <http://127.0.0.1:8765/#/login>

4. 登录页点击“管理员”或“普通用户”演示入口，即可进入原型。

需要停止服务时，在启动服务的终端按 `Ctrl+C`。

## 演示范围与数据

原型包括登录注册、用户工作台、数据管理、训练配置、模型管理、部署服务和管理后台。文件上传、训练、监控曲线、模型评估、推理调用、GPU 接入及权限配置为纯前端演示，尚未连接真实后端。GPU 接入页面中的命令为示意，请勿在服务器执行。

演示数据保存在当前浏览器的本地存储中。压缩包不包含原电脑浏览器内新增的账号、任务或其他演示记录。不同浏览器，以及 `localhost`、`127.0.0.1` 和不同端口，分别保存数据；建议始终使用同一访问地址。新标签页可能需要重新登录，浏览器清除站点数据后，本地演示记录会丢失。

## 常见问题

- **直接双击 index.html 后页面空白**：页面使用 JavaScript 模块，请按上述方法通过本地 HTTP 服务访问。
- **提示找不到 py、python 或 python3**：当前电脑需要先具备 Python 3，或使用编辑器提供的本地静态服务器，并通过 HTTP 地址打开页面。
- **提示 8765 端口被占用**：如原服务仍在运行，可直接访问原地址；也可将启动命令中的端口改为 `8767`，访问 `http://127.0.0.1:8767/#/login`。新端口的演示数据独立保存。
- **打开后显示目录列表**：请确认启动服务时所在目录包含 `index.html`，并从完整解压后的文件夹启动。

服务仅监听本机地址。若要进行远程共享或正式部署，需要另外配置访问控制与安全措施。
