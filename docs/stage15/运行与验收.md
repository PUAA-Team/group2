# 项目、筛选与报告使用说明

## 页面操作

训练项目点击蓝色名称进入详情，查看训练次数、活跃任务、最高准确率和最近实验。“修改资料”“归档项目”均使用弹窗。归档保留历史，阻止新建训练、草稿提交及排队领取；正在执行的任务继续使用原快照。恢复后可重新使用项目。

模型、数据集和项目目录可以筛选归档状态；数据集支持按最新版本选择可训练、待标注或无版本。管理员数据和模型列表增加任务类型；数据、模型、作业和审计支持创建人或操作者及日期组合筛选。日期按北京时间自然日包含起止两天。审计的操作代码为精确匹配，导出沿用当前查询条件。

API KEY列表可按服务和状态筛选，查看标识、已记录调用数、最近调用及到期时间。“有效期”弹窗支持调整未来365天内的时间，已过期密钥也能重新设置，已撤销密钥不可恢复。调用统计从升级后开始按实际密钥归属记录，旧调用和网页测试调用不分配给某个密钥；查询调用结果不重复计数。“接入示例”提供请求JSON和调用、轮询指令，使用环境变量占位，实际密钥只在创建或轮换时显示一次。

已完成评估的详情增加每类精确率、召回率、F1及样本数，可下载JSON或CSV。报告包含模型与数据版本、数据SHA256、配置、总体指标和矩阵，排除原始样本。分母为零显示“—”，真实零分保留0；Qwen沿用实际损失与Token等指标。操作记录可导出最多10000条元数据CSV，超出时需缩小筛选范围，导出文本已处理表格公式风险。

## 云端验证

最终发布镜像通过164项后端测试，前端126项通过，包含既有原型与视觉样例的回归。镜像内保留一项既有Starlette/HTTPX弃用提示，没有更换测试依赖。

| 检查 | 结果 |
| --- | --- |
| 新页面、弹窗和下载 | 33项布局、5项操作检查通过 |
| 20个侧栏入口与既有治理流程 | 99项布局、6项操作检查通过 |
| 隔离PostgreSQL | schema10→11保留、归档领取、密钥有效期/轮换并发及调用归属、审计导出共5项通过 |

布局覆盖1440、1024、390三种宽度，无整页横向溢出，受检正文和控件字号至少14px；全部检查没有JavaScript异常。实拍与摘要见[验收索引](./previews/ReadMe.md)。实际文件下载内容与API逐项对照；有效期在北京时间浏览器保存后与UTC值核对。

训练使用同一ECS内两个隔离CPU容器和合成数据，项目详情关联两次真实训练；模型效果用于检查流程。PG验收中的就绪服务为协议夹具，单独记录为非训练证据。生产模型、样本及凭据未传给外部CLI；本批没有供应商调用或Qwen CUDA回归，没有恢复本机节点。

## 部署和回退

发布目录为`/srv/model-platform/releases/20261101-15a`，前端缓存stage15-1，数据库0011_console。备份仅保存在服务器`/srv/model-platform/backups/pre-stage15-20261101`，包含数据库、storage和受限配置。发布先核对无在途执行、数据处理及智能请求，再停止写入、备份、显式迁移和切换；原记录ID与发布前核对。

迁移保留旧调用的空密钥归属，避免生成无法证明的使用记录。源码、完整日志和隔离验收现场位于`/srv/model-platform/qa/20261101-stage15`；公开接口在[OpenAPI](./openapi.json)。测试环境与生产运行目录分开，没有下载数据库或备份。

兼容回退为`20261031-14a1-compat11`，已增加新版本识别和只读写入保护。回退前核对无在途任务；停止operations，仅启动只读API，保留schema11和新增数据，不运行旧写入流程。操作如下，临时链接名称需尚未被占用：

```bash
cd /srv/model-platform/current/deploy/server
docker compose --env-file .env stop operations api
ln -s /srv/model-platform/releases/20261031-14a1-compat11 /srv/model-platform/current-rollback-stage15
mv -Tf /srv/model-platform/current-rollback-stage15 /srv/model-platform/current
cd /srv/model-platform/current/deploy/server
docker compose --env-file .env up -d --no-deps api
docker compose --env-file .env exec -T gateway nginx -s reload
```

兼容镜像已验证健康查询和拒绝写入；本批未重新恢复备份，服务器内恢复证据沿用stage14。服务器同盘备份仍需面对整块云盘丢失的风险，异地恢复尚未交付。
